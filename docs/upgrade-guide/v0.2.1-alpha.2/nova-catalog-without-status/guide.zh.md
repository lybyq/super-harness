# Nova 能力摘要不再包含发布状态

[English](guide.md) | 中文

## 变更

Nova Host 此前要求每项 Hub 能力包含已知状态，并将其返回客户端。现在 Host 接受不带状态的文档，忽略旧状态值，并从能力摘要及配置响应中剥离状态。读取该字段的自定义客户端需要调整。Runtime 绑定、配置校验、凭据与工具执行权限保持不变。这不代表能力安装已启用。

## 迁移

1. 同时更新 Nova Hub 服务端和桌面插件。从自定义客户端移除依赖状态的筛选、标签和查询参数。不要根据旧状态推断已安装或权限已授予。
2. 接受 `api/nova-hub/catalog` 与配置响应返回的不带状态的摘要字段。旧 Hub 文档中的状态字段仍可读取，但不会向客户端返回。
3. 通过 `pnpm run test:nova` 验证：目录测试接受不带状态的文档，并剥离旧状态值。使用更新后的部署打开 AI Hub，确认目录项无需发布状态即可加载。
